# Магия Масел — Сыродавленные масла в Калининграде

Превью лендинга ремесленного производства сыродавленных масел на Центральном рынке Калининграда.

- **Сайт в сети:** https://evskrutyak-bit.github.io/magiya-masel/
- **Технологии:** Чистый HTML5 / CSS3 / Vanilla JS, самодостаточный бандл, оптимизированные шрифты Onest & Cormorant Garamond, микро-взаимодействия 2026 года (spring easing, ambient glow).
